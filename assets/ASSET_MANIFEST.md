# Asset Manifest

Every asset in the game must be listed here. **All Phase 1 art is placeholder**, generated by
`tools/make_placeholders.py` (Python/Pillow drawing code, no external sources).

To replace a placeholder: drop the Blender render at any size, then either overwrite the file at the
same path or repoint the GDevelop resource (Project Manager → Resources) to the new file.
Layout code sizes ships and backdrops from screen size and the art's own aspect ratio, so new
pixel dimensions need no event changes. Ship art should face **bow up** (direction of travel) and
use a transparent background.
